## Estructura del proyecto

```
Assets/
├── Project/           ← Tu código y assets propios
│   ├── Animations/     ← Animaciones y Animator Controllers
│   ├── Audio/          ← Música y SFX
│   │   ├── Music/
│   │   └── SFX/
│   ├── Materials/      ← Materiales
│   ├── Models/         ← Modelos 3D importados
│   ├── Prefabs/        ← Prefabs
│   └── Resources/      ← Assets cargados en runtime
│   ├── Scenes/         ← Escenas del juego
│   ├── ScriptableObjects/ ← Data containers
│   ├── Scripts/        ← Todos tus scripts C#
│   ├── Shaders/        ← ShaderGraph assets
│   └── Sprites/        ← Sprites 2D
│   ├── Textures/       ← Texturas para modelos 3D
│   ├── UI/             ← Assets de interfaz
└── ThirdParty/         ← Packages o assets de terceros
```
